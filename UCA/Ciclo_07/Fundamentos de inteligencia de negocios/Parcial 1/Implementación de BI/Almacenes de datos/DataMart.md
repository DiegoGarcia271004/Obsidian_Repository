## ¿Qué es?
Es un **subconjunto de una base de datos más extensa**, donde se resguarda información de interés para un área empresarial específica o un tema particular.
Esta agrupación facilita el uso de la información para objetivos concretos y crea relaciones significativas entre los datos disponibles.

Convierte la información sin procesar o procesado en contenido estructurado y significativo para un departamento empresarial específico.
Para ello, los ingenieros de datos configuran un data mart, a través de un ETL, para recibir información de un DW o directamente de orígenes de datos externos.

## Características

### Datos específicos
Un data mart se enfoca en un área de negocio específica, por lo que su información es más detallada y específica en comparación con un DW

### Accesibilidad
Los data mart son diseñados para ser accesibles y fáciles de usar para un grupo específico de usuarios dentro de una organización

### Velocidad
Al ser una base de datos más pequeña y enfocada, los data mart pueden procesar y entregar información más rápido que un DW.
