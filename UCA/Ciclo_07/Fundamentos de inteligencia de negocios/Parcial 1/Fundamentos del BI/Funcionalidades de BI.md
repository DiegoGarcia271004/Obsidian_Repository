## ¿Qué son las funcionalidades?
Son **capacidades** que permiten recopilar, analizar y presentar [[Datos, información e inteligencia|datos]] para apoyar a la toma de decisiones en una organización. Estas funcionalidades se implementan mediante herramientas y plataformas como *PowerBI, Tableau o Looker Studio*

### Integración de datos
Permite **recopilar datos** de diferentes fuentes y combinarlos en un solo sistema.
Como algunas de las fuentes comunes:
- Bases de datos
- Sistemas empresariales
- Archivos Excel
- APIs o datos externos
Para esta funcionalidad se suele aplicar procesos ETL.

### Almacenamiento de datos
Los datos ya integrados se **almacenan** en repositorios diseñados para el análisis de estos, llamados también almacenes de datos.
Permitiendo:
- Conservar datos históricos
- Organizar la información por temas
- Facilitar consultas analíticas

### Análisis de datos
BI permite **analizar información** para identificar patrones, tendencias o problemas.
Como ejemplos:
- Análisis de ventas
- Comportamiento de clientes
- Rendimiento de productos
A través de este análisis puede ser principalmente descriptivo y diagóstico.

### Creación de reportes
Una funcionalidad fundamental es la de **generar reportes estructurados** con información clave del negocio.
Ejemplo:
- Reporte mensual de ventas
- Reporte de inventario
- Reporte financiero
Estos reportes ayudan a monitorear el desempeño de la organización.

### Monitoreo de indicadores
Las herramientas de BI permiten **medir y seguir** indicadores clave de rendimiento (Key Performance Indicator \[KPI\]) 
Ejemplos de KPI:
- Ingresos mensuales
- Margen de unidad
- Tasa de conversión
- Rotación de inventario
