El pryecto ya es un backend montado pre-productiva. Se necesita ingresar la información que deberá estar disponible en el cliente. 

- Agregar la categoría correspondiente
- Una vez creada la categoría se deberá de agregar los servicios
- Dentro del servicio, agregar el nombre, descripción (mismo nombre que el servicio), agregar precios: máximo y mínimo.
```json
{
	"max": 19.99,
	"min": xx.xx
}
```
